# Прогнозирование оттока клиентов телеком-провайдера

Кому и когда звонить из retention-команды: анализ факторов оттока, кривая удержания и модель, выделяющая клиентов с высоким риском ухода для точечной retention-кампании.

## 🎯 Бизнес-задача

Удерживать клиента дешевле, чем привлекать нового, но контактировать со всеми подряд — дорого и раздражает лояльных клиентов. Нужно понять, какие факторы значимо связаны с оттоком, как быстро компания теряет клиентов во времени, и построить модель для точечного отбора клиентов группы риска.

## 🛠 Что сделано

- Предобработка данных с разбором природы пропусков (не слепая импутация медианой)
- Проверка значимости факторов оттока тестом хи-квадрат (Contract, InternetService, SeniorCitizen)
- Кривая удержания Kaplan-Meier — корректный инструмент для право-цензурированных данных (там, где часть клиентов ещё активна и их итоговый срок жизни неизвестен), в отличие от условного «когортного» анализа
- Модель логистической регрессии на полном наборе значимых признаков (услуги, контракт, способ оплаты), а не только на демографии
- Оценка модели через precision/recall/F1/ROC-AUC с явным разбором, почему accuracy вводит в заблуждение при дисбалансе классов
- Интерпретация коэффициентов модели с поправкой на мультиколлинеарность признаков

## 🔑 Ключевые выводы

- Отток статистически значимо связан с типом контракта, типом интернета и статусом пенсионера (все p ≪ 0.001, тест хи-квадрат)
- К 12-му месяцу удержано 70.3% клиентов на месячном контракте против 99.1% на годовом и 100% на двухлетнем — разрыв формируется уже в первый год
- При дисбалансе классов (26.5% оттока) базовая accuracy «всегда предсказывать не уйдёт» уже равна 73.5% — итоговая модель (74.4% accuracy) оценивается по recall (79.7%) и ROC-AUC (0.844), а не по accuracy
- Fiber optic интернет и оплата через Electronic check повышают риск оттока даже с учётом остальных факторов; двухлетний контракт, OnlineSecurity и TechSupport — снижают
